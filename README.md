# 业余无线电台操作技术能力验证 · 刷题与模拟考试系统

仿照 `https://zhipu.allspectrum.cn:9528/CRAC/crac/login_student.html` 的界面风格制作的本地刷题 + 模拟考试工具，
题库来自附件 `20250809124154_2851.zip` 中的 A / B / C 类题库 PDF。

## 一、使用方式

1. 双击打开 `index.html`（推荐 Chrome / Edge）。
2. 账号与密码都是可选的：直接点「登录」即可进入，也可以填写账号作为显示名称（本工具为本地练习用，无后端、无真实账号校验）。
3. 在首页选择 A / B / C 类，然后选择「顺序刷题」「随机刷题」「模拟考试」或「错题本」。

> 也可以在此目录执行 `python -m http.server 8899`，再访问 <http://127.0.0.1:8899/>。
> 所有数据都保存在浏览器本地（localStorage），无需联网。

## 二、考试规则（已内置到「模拟考试」）

| 类别 | 题量 | 单选 | 多选 | 答题时间 | 合格标准 |
|------|------|------|------|----------|----------|
| A 类 | 40 题 | 32 | 8 | 40 分钟 | 答对 30 题及以上 |
| B 类 | 60 题 | 45 | 15 | 60 分钟 | 答对 45 题及以上 |
| C 类 | 90 题 | 70 | 20 | 90 分钟 | 答对 70 题 |

- 多选题需与标准答案**完全一致**，多选或少选均不得分。
- 模拟考试到点自动交卷；交卷后给出得分、合格判定、用时、单选 / 多选正确率与错题回顾。
- 未作答的题目按答错处理，并自动进入错题本。

## 三、功能一览

- **登录页**：沿用原系统的蓝色主题与卡片式登录框（账号 / 密码 / 下次自动登录 / 忘记密码 / 注册），账号与密码均可留空。
- **刷题**：顺序 / 随机两种模式，支持按章节（如 1.1.1）筛选；单选点选即判，多选点「提交答案」判分；可随时「显示答案」。
- **答题卡**：题号网格，练习模式显示对 / 错 / 已看状态，考试模式显示已作答状态，点击可跳转。
- **错题本**：A / B / C 分别记录；答对后自动移出，也可手动移出或清空；支持「错题重做」。
- **模拟考试**：随机组卷、倒计时（最后 5 分钟变红闪烁）、答题卡、交卷二次确认、成绩页。
- **快捷键**：练习模式下 `← / →` 翻题，`1~4` 选择选项。

## 五、题库来源与处理说明

- 全部题目从附件的 PDF 题库解析得到：**A 类 683 题（单选 547 / 多选 136）、B 类 1143 题（单选 947 / 多选 196）、C 类 1282 题（单选 1072 / 多选 210）**。
- 附图题目的电路图从 `总题库附图标记.pdf` 中提取，共 53 张，按题号（如 `LK0734`）与题目对应。
- 原题库中**正确答案固定排在选项首位**（导出格式所致）。为避免“答案永远是 A”，程序在显示时按题号做**稳定乱序**（同一道题每次显示顺序一致，便于错题回顾），答案随选项同步移动，判分逻辑不受影响。
- 原题库有 2 道题标注为单选、实为多选（如 `MC1-0014`），已按标准答案处理。
